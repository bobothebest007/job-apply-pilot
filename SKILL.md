# Job Apply Pilot

1. Read the user's current application profile and submission/tracking preferences. Open the requested role in an authorized signed-in browser, verify its requirements, and check the tracker for the job ID or URL. Use verified profile facts; do not infer qualifications or sensitive answers from the job description. Continue when the role and any existing tracker entry are clear.
2. If an installed autofill extension supports the form, run it once. Inventory the entire application, including demographic, consent, and legal sections near the bottom. On embedded forms, use focused reads of labels, required status, values, and attachment names; long prose can truncate full snapshots. Treat extension completion counts as advisory. Verify contact details, location, work authorization/sponsorship, résumé filename, and every required field on the form itself. Batch grounded browser actions only when the selected driver supports it, then verify selections and uploads. If an upload is still absent, ask the user to attach it. Continue when the completed and missing fields are known.
3. Ask about unanswered factual or sensitive questions together, using the form's exact wording. Do not transfer employer-specific history, location, or commute answers to a different application. Follow the user's current directions for applicant agreements; if required agreements are preauthorized, accept them without asking again, while checking any factual certification separately. For open-ended motivation questions, combine the job description with verified experience without inventing experience or personal motives. Continue when every required answer is grounded or the user has identified a blocker.
4. Review the completed form and attachment, submit once, and check for a visible receipt or confirmation. Correct validation errors and verify again if needed. Continue to tracking only after submission is confirmed.
5. If a tracker is required, search it again for the job ID or URL to prevent duplicates. Inspect its row layout; where IDs or statuses are prefilled, use the first blank application row instead of blindly appending. Preserve formulas and status cells. Record the required date, employer, title, and URL, then verify the row and saved state. Prefer an authorized tracker integration when available; use browser cell edits as a fallback. Finish when the confirmed submission is recorded or report the precise tracking blocker.
